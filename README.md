# 居家環境與外出建議代理人

國立中興大學｜物聯網應用與資料分析｜第二組專題提案

本專題探討如何整合單一房間的溫濕度量測、中央氣象署鄉鎮預報與住戶回饋，協助住戶判斷何時除濕、開窗或外出。代理人提供建議與依據，家電由住戶操作。

## 研究設計

1. **資料蒐集**：以 ESP32 量測單一房間的溫度與相對濕度，保存具取得時間與適用時段的預報快照，並以操作日誌與住戶確認建立操作事件標記。
2. **可追溯建議與主動詢問**：代理人以限定工具取得證據，回覆附來源、適用地點與時段及規則版本。系統合併候選事件並限制詢問頻率，分別保存模型推論、住戶確認及未知狀態。
3. **評估**：規劃蒐集約兩週的住宅量測及回饋。以完整事件為單位，保留較晚事件供固定規則與決策樹比較。以同批事件回放評估詢問負擔，並以共同情境檢核回答的證據一致性。

## 專題狀態

目前為提案階段。預期交付操作標記資料、建議原型及可重現的評估流程。操作辨識表現、詢問負擔與證據一致性待實測。兩週單房間的資料用於界定單點感測在本個案中的應用範圍，季節變異留待後續研究。
